DOCKLINE — 2D top-down open-world crime game set in Port Meridian: six boat-chase jobs through canals, piers and open water, wanted 1–5 with patrol boats, combat, HUD + minimap + tide indicator. Built for the make.fun gta6-01 competition.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
